# Personal Finance App

## Как создавался и как работает сервис

Задание было на создание консольного приложения для управления личными финансами. По заданию нужно было сделать авторизацию пользователей, кошелёк с доходами и расходами, категории с бюджетами, сводку по операциям и сохранение данных в файл, чтобы данные сохранялись даже после закрытия программы.

Для начала было определено, какие данные нужны для работы приложения: у пользователя есть логин, пароль и UUID, у кошелька -- баланс, список операций и список категорий, у операции -- сумма, тип (доход или расход), категория и дата, у категории название и необязательный бюджет.

Код разделён на несколько классов:

- `Main` отвечает за консольное меню, принимает ввод пользователя и обрабатывает выбранное действие
- `ConsoleAuth` работает с файлом пользователей, регистрирует новых и ищет пользователя по логину и паролю
- `User` хранит данные пользователя: UUID, логин и пароль
- `Wallet` хранит кошелёк пользователя: баланс, операции и категории, а также считает суммы доходов и расходов
- `WalletService` работает с файлом кошельков, сохраняет и загружает данные через Gson
- `Operation` создан для объектов операций (доход или расход)
- `Category` создан для категорий и бюджета по ним
- `OperationType` -- это enum с двумя значениями: `INCOME` и `EXPENSE`

### Авторизация пользователей

Приложение поддерживает несколько пользователей. Сначала нужно зарегистрироваться: ввести логин и пароль. Если пользователь с таким именем уже есть, повторная регистрация не проходит. 
После регистрации можно войти по логину и паролю.

Авторизация потоковая, в один момент времени в приложении может работать только один пользователь. После его выхода из аккаунта может авторизоваться другой пользователь.

Список пользователей хранится в файле `users.txt`, в каждой строке записаны UUID, логин и пароль.

### Как работает кошелёк

После авторизации программа через `WalletService` или находит уже существующий кошелёк по UUID пользователя, или создаёт новый. Кошелёк хранит все категории операций и сами операции пользователя.

Баланс равен сумме доходов за вычетом суммы расходов, после каждой новой операции итоговый баланс пересчитывается.

### Категории и бюджеты

Перед добавлением операции нужно создать хотя бы одну категорию. При создании каждой категории программа спрашивает, нужен ли бюджет по данной категории, и если пользователь выбирает "Да", появляется возможность ввести размер бюджета. 
Если "Нет", категория сохраняется без бюджета.

### Добавление операций

Пользователь выбирает тип операции (доход или расход), вводит сумму и номер категории, после чего операция добавляется в кошелёк и сохраняется в файл.

Если добавляется расход и у категории определен бюджет, программа суммирует все расходы по этой категории. Когда сумма расходов становится больше заданного бюджета, 
в консоль выводится предупреждение: "!!! Внимание: превышен бюджет по данной категории !!!".

Также есть проверки на некорректный ввод: пустую сумму, отрицательное число, неверный тип операции или номер категории, которого нет в списке.

### Сводка

В сводке выводятся общая сумма доходов и расходов, доходы по категориям и расходы по категориям. Для расходов дополнительно показывается бюджет и то, превышен ли он.

Если общие расходы больше общих доходов, в конце сводки выводится предупреждение: "!!! Внимание: расходы превысили доходы !!!".

### Как сохраняются данные

Для хранения кошельков в проекте использовалась библиотека Gson. Все кошельки хранятся в JSON файле `wallets.json`. При добавлении операции или категории, а также при выходе из аккаунта или из программы данные сохраняются в этот файл. За счёт этого данные не удаляются после закрытия программы, а остаются в файле.

При следующем входе кошелёк пользователя загружается из файла по его UUID.

## Инструкция для пользователя

### 1. Запуск программы

Для работы с проектом необходимо скачать его из репозитория на GitHub — https://github.com/Nadya-a/PersonalFinanceApp.git — и открыть его в IntelliJ IDEA.

В проекте уже подключена библиотека Gson (`lib/gson-2.11.0.jar`). Если IntelliJ не подхватит её автоматически, нужно добавить jar-файл из папки `lib` в Libraries модуля.

Для запуска программы надо запустить метод `main()` в классе `Main`.

После запуска в консоли появится меню:

1. Зарегистрироваться
2. Войти
0. Выход
Введите номер действия, которое хотите совершить:

Чтобы выбрать действие, нужно ввести его номер и нажать на Enter.

Если нужно начать с пустыми данными, перед запуском можно удалить файлы `users.txt` и `wallets.json` (они создаются программой во время работы).

### 2. Регистрация и вход

Введите в консоль `1`, придумайте имя пользователя и пароль. Если поля оставить пустыми, или логин занят, регистрация не пройдёт.

Чтобы войти, введите `2`, затем логин и пароль. При успешном входе откроется меню работы с кошельком:

1. Посмотреть баланс
2. Посмотреть историю операций
3. Добавить операцию
4. Добавить категорию
5. Показать сводку
6. Выйти из аккаунта
0. Выйти из программы

### 3. Добавление категории

Введите в консоль `4` и название категории. Дальше программа спросит, нужен ли бюджет:

1. Да
2. Нет

Если выбрать `1`, появится возможность ввести размер бюджета. Если выбрать `2`, шаг установки бюджета пропустится и категория сохранится без бюджета.

### 4. Добавление операции

Это действие получится выполнить только после добавления категорий, потому что для создания операции уже должна быть добавлена хотя бы одна категория. 
Затем введите `3`, выберите тип операции:

1. Доход
2. Расход

После этого введите сумму и номер категории из списка. Операция сохранится в кошелёк. Если это расход и бюджет по категории превышен, программа покажет уведомление.

### 5. Баланс, история и сводка

Пункт `1` вывдит текущий баланс кошелька.

Пункт `2` выводит список всех операций: дату, тип, сумму и категорию.

Пункт `5` выводит общую сводку по всем операциям пользователя: весь доход, все расходы, доходы и расходы по категориям, бюджет и было ли его превышение.

### 6. Выход из аккаунта и из программы

Чтобы выйти из аккаунта, введите `6`. Данные кошелька перед выходом пользователя из программы автоматически сохраняются в файл.

Чтобы полностью закрыть программу, введите `0`.
